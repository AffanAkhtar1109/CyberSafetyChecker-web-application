# 🛡️ Cyber Safety Checker

A beginner-friendly web application designed to help users identify potential warning signs in suspicious messages, emails, and website URLs.

## 📌 About the Project

**Cyber Safety Checker** is a cybersecurity awareness tool that analyzes user-provided messages and URLs for common warning signs associated with phishing and suspicious online activity.

The application provides a simple risk level, explains the detected warning signs, and gives safety recommendations to help users make safer decisions online.

> ⚠️ **Disclaimer:** This tool provides basic security checks and awareness guidance. It does not guarantee that a message or website is safe or malicious.

## ✨ Features

* 🔍 **Message Analysis**

  * Analyze suspicious messages or emails
  * Identify potential warning signs
  * Provide a risk level
  * Give safety recommendations

* 🌐 **URL Checker**

  * Check for basic suspicious URL characteristics
  * Detect HTTP instead of HTTPS
  * Identify unusually long URLs
  * Detect IP-address-based URLs
  * Identify suspicious URL patterns

* 🛡️ **Cybersecurity Tips**

  * Safe browsing recommendations
  * Password safety tips
  * OTP and phishing awareness
  * Two-factor authentication guidance

* 📱 **Responsive Design**

  * Works on desktop and mobile screens
  * Simple and user-friendly interface

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Enter a suspicious message or URL.
5. Click the appropriate analysis button.

No server or installation is required.
